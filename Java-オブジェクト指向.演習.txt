オブジェクト指向	
	
問1.	オブジェクト指向とは何ですか？以下の中からもっとも適切な説明を1つ選びなさい。
	
	A. 処理を関数としてまとめる考え方
	B. データと処理を1つの単位（オブジェクト）としてまとめて扱う考え方
	C. すべての処理をif文で分岐して書く考え方
	D. ファイルの入出力を効率化するための技法
	→B
	
問2.	「クラス」と「オブジェクト」の関係として正しいものはどれですか？
	
	A. クラスはオブジェクトの一種である
	B. オブジェクトはクラスを編集したものである
	C. クラスはオブジェクトの実体である
	D. クラスは設計図、オブジェクトはそれをもとに作られた実体である
	→D
	
問3.	クラスとオブジェクトの違いを、日常的な例を使って説明しなさい。
	→クラスは母親のカレーのレシピ、オブジェクトはそれがインスタンス化した実体。母親のカレーそのもの。
	
問4.	オブジェクト指向の利点として適切なものを、次の選択肢からすべて選びなさい。（複数選択可）
	
	A. プログラムを現実世界のモデルに近い形で設計できる
	B. 同じクラスから複数のオブジェクトを作成でき、再利用性が高い
	C. 処理とデータが分離されており、変更が簡単である
	D. 共通の処理を親クラスにまとめることで、保守性を高められる
	E. 他のプログラミング言語より実行速度が速くなる
	→A,B,D
	
問5.	次のうち、オブジェクト指向プログラミングに対応している言語をすべて選びなさい。（複数選択可）
	
	A. Python
	B. HTML
	C. C++
	D. JavaScript
	E. SQL
	→A,C,D

第8章：オブジェクト指向（カプセル化）							
							
問1.	オブジェクト指向における「カプセル化」とは何か、簡単に説明してください。						
	また、カプセル化を適用することで得られるメリットを2つ挙げてください。						
→カプセル化とは、データとメソッド（データに対する操作）を一つのクラスにまとめることで、外部から直接データを書き換えられないよいうにすることです。
→カプセル化のメリットとしては、外部から直接アクセスさせないことで、データの保護やバグの防止（あり得ない値が入るのを防ぐ）などが挙げられる。							
問2.	以下のJavaクラスは、カプセル化の原則に違反しています。						
	カプセル化を適用するように修正してください。						
							
	修正前のコード					
							
	class Person {						
	    String name;						
	    int age;						
	}						
										
	修正後のコード
	
	class Person {						
	    private String name;						
	    private int age;
	    //1.外部から直接アクセスできない
	    public String getName() {
	    	return name;
	    }
	    public void setName(String name) {
	    	this.name = name;
	     //2.nameにgetterとsetterを
	    }
	   
	    public int getAge() {
	    	return age;
	    }
	    public void setAge(int age) {
	    	this.age = age;
	     //3.ageにgetterとsetterを
	    }
	}

第8章：オブジェクト指向（継承）							
							
問1.	オブジェクト指向における「継承」とは何か、簡単に説明してください。						
	また、継承を使うことで得られるメリットを2つ挙げてください。						
	→継承とは、親クラスの性質や機能を引き継いで、新しいクラス（子クラス）を作る仕組みのこと。
	→継承のメリットとしては、共通の処理を親クラスに一度書くだけで済むため、同じコードを何度も書かずに済む点。
	また、共通部分の修正が必要になった際、親クラスだけ直せば引き継いだすべてのクラスに反映されるため、ミスが減る点。					
												
問2.	以下のJavaのクラスでは、「Student」 クラスが 「Person」 クラスのプロパティを重複して定義しています。						
	継承を使ってコードを改善 してください。						
							
	修正前のコード						
							
	class Person {						
	    String name;						
	    int age;						
	}						
							
	class Student {						
	    String name;						
	    int age;						
	    String studentId;						
	}						
										
	修正後のコード	
	//親クラス
	class Person{
		String name;
		int age;
	}
	//子クラス
	class Student extends Person{
		String studentId;
	}

第8章：オブジェクト指向（ポリモーフィズム）							
							
問1.	オブジェクト指向における「ポリモーフィズム（多態性）」とは何か、簡単に説明してください。						
	また、ポリモーフィズムを使うことで得られるメリットを2つ挙げてください。						
	→ポリモーフィズムは、同じメソッドを呼び出しても、呼び出し先のオブジェクトによって異なる動きをする仕組みのこと。		
	→メリットとしては、コードが単純化すること、拡張性が高いという点が挙げられる。既存のコードを修正せずに簡単に機能を追加できたり、条件分岐を減らせたり、非常に便利である。
	
問2.	以下のコードでは、動物（Animal）クラスのサブクラス（Dog, Cat）がそれぞれ makeSound() メソッドを実装せず、適切に振る舞いを定義できていません。						
	ポリモーフィズムを適用し、各動物ごとに異なる makeSound() の動作をするように修正 してください。						
							
	修正前のコード						
							
	class Animal {						
	    void makeSound() {						
	        System.out.println("Some sound...");						
	    }						
	}						
							
	class Dog extends Animal {						
	}						
							
	class Cat extends Animal {						
	}						
			
	修正後のコード
					
	class Animal{
	void makeSound() {
		System.out.println("Some sound...");
		}
	}

	class Dog extends Animal{
		@Override
		void makeSound() {
			System.out.println("Bark!");
		}
	}

class Cat extends Animal{
		@Override
		void makeSound() {
			System.out.println("Meow!");
		}
	}					
問3.	以下のコードはなぜ「ポリモーフィズム」を使っていると言えるのでしょうか？						
							
	Animal a = new Cat();						
	a.eat();						
							
	選択肢：						
	A. Catクラスをnewしているから						
	B. Animalクラスのメソッドが使われているから						
	C. 変数の型はAnimalだが、中身はCatであり、Catのメソッドが呼ばれているから						
	D. eat()メソッドは一つしか定義されていないから						
	→C						
							
問4.	次のうちポリモーフィズムを使っているコードはどれですか？
