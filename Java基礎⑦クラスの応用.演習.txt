問3.	Employeeクラスにequalsメソッドをオーバーライドして、社員IDが同じ場合に等しいと判定するようにしてください。
	Employeeクラスのインスタンスを作成し、equalsメソッドを使って比較するプログラムを作成してください。
	※ equalsメソッドは、社員IDが同じかどうかのみ判定できればOK。（nullチェックやhashCodeの実装は不要）

	package jp.co.aforce.sample;

	class Employee1 {
		String employee1Id;
	
		Employee1(String id){
			this.employee1Id = id;
}
	
		@Override
		public boolean equals(Object obj) {
			if(obj instanceof Employee1) {
			
				Employee1 other = (Employee1) obj;
			
				return this.employee1Id.equals(other.employee1Id);
		}
		
			return false;
	}
}

	public class Employee2 {
		public static void main(String[] args) {
			Employee1 a = new Employee1("A3592514");
			Employee1 b = new Employee1("A3592514");
		
			System.out.println("同じ人ですよね？:" + a.equals(b));
	}

}

問3.	任意の数の整数の和を計算するメソッドを作成し、複数の引数を渡して結果を表示するプログラムを作成してください。
	※ 任意の数の整数は、可変長引数（int...）を使用してください
	
	package jp.co.aforce.sample;

	class FreeCalMachine {
		int sumAll(int...numbers) {
			int total = 0;
			//numbersは配列扱い
			for(int n : numbers) {
				total += n;
			}
			return total;
		}
	}

	public class FreeCalculator{
		public static void main(String[] args) {
		FreeCalMachine fcm = new FreeCalMachine();
	
		System.out.println(fcm.sumAll(1,36,28,39));
		System.out.println(fcm.sumAll(56,31,33,22));
		System.out.println(fcm.sumAll());
		}
	}
