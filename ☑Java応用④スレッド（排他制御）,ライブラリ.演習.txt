第15章：スレッド（排他制御）	
問1.	Runnable インターフェイスを実装した MyRunnable クラスを作成し、
	run() メソッドで「Hello from a thread!」と表示するプログラムを作成してください。
	MyRunnable を使ってスレッドを開始してください。
	
package jp.co.aforce.sample;

public class MyRunnable implements Runnable{
	@Override
	public void run() {
		System.out.println("Hello from a thread!");
	}
	public static void main(String[] args) {
		Thread thread = new Thread(new MyRunnable());
		thread.start();
	}
}

問4.	次のコードスニペットの出力として正しいものはどれですか？
	public class Counter {
	    private int count = 0;
	
	    public synchronized void increment() {
	        count++;
	    }
	
	    public int getCount() {
	        return count;
	    }
	
	    public static void main(String[] args) {
	        Counter counter = new Counter();
	        Thread t1 = new Thread(() -> {
	            for (int i = 0; i < 1000; i++) {
	                counter.increment();
	            }
	        });
	
	        Thread t2 = new Thread(() -> {
	            for (int i = 0; i < 1000; i++) {
	                counter.increment();
	            }
	        });
	
	        t1.start();
	        t2.start();
	
	        try {
	            t1.join();
	            t2.join();
	        } catch (InterruptedException e) {
	            e.printStackTrace();
	        }
	
	        System.out.println.getCount());
	    }
	}
	
	A. 0
	B. 1000
	C. 2000
	D. 不定
	→C

問1.	java.time.LocalDate クラスを使って、現在の日付を取得し、1週間後の日付を表示するプログラムを作成してください。

問4.	LocalDateTime を使って現在日時を表示する問題
	現在の日時を取得し、「2025年4月11日 15時30分」のような形式で出力してください。

package jp.co.aforce.sample;

import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

public class Library4 {
	public static void main(String[] args) {
		LocalDateTime now = LocalDateTime.now();
		DateTimeFormatter fmt = DateTimeFormatter.ofPattern("yyyy年M月d日 h時mm分");
		System.out.println(now.format(fmt));
	}
}
